# Chetan Patil — Civil Engineer Portfolio

A responsive, static portfolio website built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository named `chetan-patil-portfolio`.
3. Upload `index.html`, `style.css` and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. GitHub will provide a public website address, usually:
   `https://YOUR-USERNAME.github.io/chetan-patil-portfolio/`

## Before publishing
- Confirm the education dates and grades.
- Add a professional headshot if desired.
- Add a contact email and phone/WhatsApp number if Chetan wants them public.
- Add real project photographs/details only with permission.
- The Indian Concrete Institute entry is shown as expired in February 2026, based on the supplied LinkedIn screenshot.
